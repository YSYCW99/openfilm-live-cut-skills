# 直播文本风险自检

输入：高光候选清单、每条完整 `source_text`（或可按时间定位的全文）、目标平台、用户禁用词与内容限制。可接收任意来源的同结构清单，不要求自动调用选段技能。

不能只扫描 `core_content` 或钩子摘要：摘要可能省略原音里的风险。无法取得完整原文时，将该条标为 `needs_review`，列出缺失材料，不声称扫描完成。

## 判断规则

- 检查“最、第一、永久、保证、100%、顶级”等用语的实际语境，区分营销夸张、数字事实、引用、否定和日常表达。“最近”“第一个问题”不因子串命中自动判违规。
- 对“微信、V、私聊、加我、联系方式、私域”等检查是否实际要求添加个人账号、进私群或转移交易；字母V、讨论微信功能或客观引用不能直接判为导流。
- 检查保证收益、保本、稳赚、无依据的量化承诺、敏感表达与用户禁用内容。明确区分禁用清单命中、上下文疑点和需要来源核实的事实，不把所有争议说法都当成已违法。
- 保留证据原句和时间位置。转写不确定处标 `needs_review`；不得通过改字幕掩盖原声中的风险，也不得把主播不确定的表达改成确定结论。
- 默认高风险不进入可执行清单，但完整记录在 `excluded`。上层如有明确处置规则，遵守该规则并记录决定。此步骤不修改视频、发布内容或执行平台操作。

## 输出

JSON 对象：`scope`、`eligible`、`excluded`、`needs_review`、`summary`。

每条保留输入字段并增加：

- `risk_level`：`low`、`medium`、`high` 或 `unknown`。
- `risk_reason`：判断理由，不空写“违规”。
- `evidence`：数组；每项含 `quote`、`category`、`source_start`、`source_end`。若原文只有段级时间，使用段级定位并注明精度，不伪造词级时间。
- `decision`：`retain`、`exclude` 或 `needs_review`。
- `suggested_action`：保留备注、整段排除或核对原音/资料；不要擅改发言含义。

`scope` 要说明检查的是原文、钩子还是发布文案，以及未覆盖的内容。低风险表示本轮文本未发现明显问题，不等于“安全认证”。只做文本语义检查，不识别画面、图片、OCR、账号资质或实际商品。涉及最新平台规则或法律结论时，只有在当前任务允许查证且取得适用来源后才作具体判断；否则列为待核验事项。
